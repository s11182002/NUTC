# NUTC MARKET（Vue 3 版）

以 Vue 3、Vite 重建的中科大校園二手市集前端。首頁、商品搜尋與篩選、商品詳情、收藏、會員註冊與登入、拍照上架與管理、校園揪團、校內地點面交安排及檢舉紀錄都在同一個 Vue 專案中。

## 在 VS Code 執行

1. 安裝 Node.js 20.19 以上版本。
2. 在 VS Code 開啟本資料夾，開啟終端機執行 `npm install`。
3. 執行 `npm run dev`，開啟終端機顯示的網址。
4. 要產生靜態網站，執行 `npm run build`。建置結果在 `dist/`。

頁面使用 `#/products` 等網址，重整頁面也能維持所在頁。若用本機 Vite 執行，資料屬於不同的瀏覽器來源，原本部署網址的 localStorage 不會自動搬過來。

## 資料與限制

這是前端展示版。商品、帳號、收藏、揪團與檢舉紀錄都儲存在目前瀏覽器的 localStorage，沿用原版的資料鍵名稱；不同裝置之間不會同步。註冊並未寄送校園信箱驗證信，忘記密碼只在本機修改，檢舉紀錄沒有送給管理員，聯絡賣家也沒有站內訊息後端。請勿用真實密碼測試。若要正式公開供全校使用，需建立後端、資料庫、正式驗證與權限控管。

商品示範資料取自原版網站；圖片與 LOGO 保留新版配色。Vue 原始碼位於 `src/`，圖片位於 `public/images/`。

## 功能二：拍照快速上架

登入後點「我要上架」。在「拍照快速上架」區塊可按「開啟相機」直接拍照，或按「手機拍照／選擇圖片」使用手機相機／相簿。照片會縮小後顯示預覽，再填寫名稱、價格等資料上架。相機權限由瀏覽器決定；電腦版請使用 `localhost`，手機版請透過 HTTPS 開啟網站。單一照片仍受瀏覽器 localStorage 容量限制。

## 功能四：校內地圖約定

點選「面交地圖」或從商品詳情選「約定校內面交」，切換三民／民生校區，再按校園配置圖上的地點標記。選擇商品、日期與時間後儲存。未指定商品時建立個人草稿；選擇自己上架的商品以外、且有賣家帳號的商品時，建立等待賣家確認的提議。同一瀏覽器切換到賣家帳號後，可在「面交地圖」確認或婉拒。此流程只是前端展示，並不會通知另一台裝置上的賣家。圖上的標記依使用者提供的校園配置圖人工定位，屬約定位置的參考；實際碰面仍須確認入口與現場位置。
